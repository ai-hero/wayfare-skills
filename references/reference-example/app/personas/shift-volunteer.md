# Shift volunteer

cites: role:desk-volunteer@1

- **In this app:** works the returns desk on a busy Saturday, checking tools as
  members bring them back.
- **Context:** on the desk tablet, with a queue of members; volunteers a few
  Saturdays a year, so remembers no procedure between shifts.
- **Needs from the screens:** the oldest waiting tool first, and a check that
  asks the right questions for that kind of tool.
- **Frustrations today:** the condition check lives in a regular volunteer's
  head, so returns pile up on the shelf when that volunteer is away.
