entity: loan@2

# Loan

One tool lent to one member, from hand-over to return.

- **Owned by:** this app.
- **Identity:** `loan_id`, generated by the store.
- **Grain:** one per hand-over. A reservation that is never picked up is not a
  loan.

## Attributes

| Attribute | Type | Required | Notes |
| -- | -- | -- | -- |
| loan_id | string | yes |  |
| tool_id | string | yes |  |
| member_id | string | yes |  |
| handed_over_on | date | yes | set by the server at checkout |
| due_on | date | yes | chosen at checkout; seven days by default |
| returned_on | date | no | set when the tool comes back |
| condition_on_return | enum | no | `good`, `worn`, `broken`; set by the condition check |

## Relationships

- **tool:** many-to-one, required.
- **member:** many-to-one, required.

## Rules

- A loan cannot be created without `due_on`.
- A loan is open until `returned_on` is set, and closed only once
  `condition_on_return` is recorded too.
