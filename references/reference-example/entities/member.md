# Member

A neighbor who has joined the library and may borrow tools.

- **Owned by:** this app. Sign-in belongs to the identity provider; only its
  subject id is stored here.
- **Identity:** `member_id`, generated by the store.
- **Grain:** one per person who has joined.

## Attributes

| Attribute | Type | Required | Notes |
| -- | -- | -- | -- |
| member_id | string | yes |  |
| subject | string | yes | from the session, never from the request |
| display_name | string | yes | shown at the desk |
| joined_on | date | yes | set by the server |
| active_loans | integer | derived | count of open loans; never stored |

## Relationships

- **loan:** one-to-many.

## Rules

- A member may hold at most three open loans at once.
